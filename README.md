# M 6:33

Protótipo para o celular. O nome é o versículo 33 do capítulo 6 de Mateus: buscar primeiro o reino de Deus. Um lembrete leve para meditar na Bíblia antes dos apps que distraem, com a sequência de dias e a árvore que cresce.

Tudo fica no próprio aparelho. Depois da primeira abertura, o protótipo funciona sem internet.

A pergunta volta à meia-noite de cada dia. Não é uma folga de 24 horas. A sequência só zera se um dia ficar sem o sim verdadeiro. A maior sequência fica guardada.

Este protótipo não cobre outro app de verdade. No Android, isso depende de permissões do sistema. Aqui dá para percorrer a pergunta, o silêncio e a árvore.
